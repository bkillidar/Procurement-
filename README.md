# Development Ops

Operations and procurement management for a residential real-estate development company.
Next.js (App Router) · TypeScript · Tailwind · Supabase (Postgres, Auth, Storage, RLS) · Vercel.

See **docs/SETUP.md** for the step-by-step setup (local, Supabase, GitHub, Vercel).
See **docs/ARCHITECTURE.md** for the architecture, data model and routes.

## Everyday commands

| Command | What it does |
|---|---|
| `npm run dev` | Start local dev server at http://localhost:3000 |
| `npm run build` | Production build (what Vercel runs) |
| `npm run lint` | Lint |
| `npm run typecheck` | TypeScript check |
| `npm test` | Unit tests |
